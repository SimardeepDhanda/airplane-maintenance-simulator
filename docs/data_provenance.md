### Terms

The repository page states no explicit licence. It asks publications to acknowledge the repository and
the data donors, and says users employ the data at their own risk. The data.nasa.gov catalogue entry
could not be retrieved from the build environment, so its licence field is unconfirmed. This project
does **not** redistribute the dataset; `scripts/download_data.py` fetches it from the NASA-linked source.

### Measured FD001 structure (2026-11-17)

| File | Rows | Units | Columns |
|---|---|---|---|
| `train_FD001.txt` | 20,631 | 100 | 26 |
| `test_FD001.txt` | 13,096 | 100 | 26 |
| `RUL_FD001.txt` | 100 | – | 1 |

Readme: FD001 has 100 train and 100 test trajectories, one condition (sea level), one fault mode (HPC
degradation). Train trajectories run to failure; test trajectories end before failure, and
`RUL_FD001.txt` gives the true RUL at each test unit's last cycle. Rows have trailing spaces. The
readme contains non-UTF-8 (Windows-1252) characters, so it is stored verbatim.

### Access notes

- From the development container, `nasa.gov` and `data.nasa.gov` were blocked by the network proxy
  (HTTP 403); the S3 link was reachable. Elsewhere, any browser can fetch the S3 link.
- If automatic download fails, download the zip manually and pass `--source /path/to/file.zip`.
  A checksum mismatch is an error: no substitute data is used.

## Synthetic data

All airline data (aircraft, flights, airports-as-stations assignments, facilities, parts, costs) is
generated by seeded code in later phases and labelled as simulated in the UI. A tiny synthetic fixture
is used in unit tests (`ml/tests/test_cmapss.py`) and is never presented as NASA data or results.
